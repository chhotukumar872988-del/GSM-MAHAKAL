# GSM~MAHAKAL website

A static, responsive landing page. Upload this entire folder to Netlify, GitHub Pages, or any standard web host; no build step is needed.

## Admin editor

Open `admin.html` directly to edit the brand, hero text, social links, support banner, every tool, and every driver. It is intentionally not linked anywhere on the public website. You can add or remove cards and export/import JSON backups.

This static editor stores its edits only in the current browser. It is ideal for preparing content locally. A secure, live online admin panel that updates the public website for all visitors requires a backend/database and user authentication.

## Code customization

- Replace the social `href` values in `index.html` with your WhatsApp, Telegram and YouTube links.
- Replace each `href="#"` tool/driver link with its real download page.
- Edit card titles and descriptions directly in `index.html`.
- Colors are collected at the top of `style.css` as CSS variables.

The visual mark is an original CSS-built placeholder, so you can safely replace it later with an owned logo asset.
